# Project history archive

This is the shared home for completed work and historical evidence. Start with
the appropriate index when investigating a past result or bug.

| Folder | Contents |
| --- | --- |
| [app](app/README.md) | Dated application audits, bug fixes, and validation records. |
| [research](research/README.md) | Completed stock and strategy experiments, protocols, manifests, and results. |

Keep current application guides in [docs](../docs/README.md), and script sources
and reusable analysis programs in [research](../research/README.md). New generated
exports and temporary outputs belong in the ignored `artifacts/` directory.

Preserve each archived record's dates, assumptions, and results. Add future
records to the appropriate subfolder and its index. Historical results describe
the version and conditions tested at the time; consult current guides before
assuming that an old result or limitation still applies.
